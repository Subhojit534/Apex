# APEX Knowledge Base

This directory houses domain operational runbooks, system architecture blueprints, incident post-mortem retrospectives, and telemetry alert thresholds for NOVA's cognitive reasoning pipeline.

## Directory Layout
- `runbooks/`: Guided mitigation instructions for common infrastructure outages (DB deadlocks, memory leaks, cert expiry).
- `blueprints/`: Topology models describing service dependencies, RPC call graphs, and failover topologies.
- `heuristics/`: Domain heuristics and failure signatures mapped against incident categories.
