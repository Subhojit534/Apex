# APEX Demonstration Scenarios

This directory provides interactive scenarios and mock telemetry generators to exercise the APEX platform during demos and development testing.

## Included Scenarios (Phase 0)
- **High Latency Cascade**: Simulates database connection pool exhaustion on the `payment-gateway` service.
- **WebSocket Protocol Verification**: Tests bidirectional real-time synchronization between Express backend, Electron desktop assistant, and mobile PWA client.
- **Gemini Root-Cause Synthesis**: Tests the server-side `@google/genai` integration with graceful fallback mode.
